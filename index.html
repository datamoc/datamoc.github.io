Play Pong

Player 0CPU 0

Controls

Move with Arrow Up and Arrow Down, or W and S.

Press Space to start or pause. First to 7 wins.

Libraries and loading
  • mwg.Generator provides deterministic serves. MWG is included locally in vendor/mwg.global.js.
  • Pyroeis runs the editable Lua opponent strategy in a Web Worker. Its bundle is included locally in vendor/pyroeis.bundle.js.
  • mwg-retro-audio provides playTone. The page loads it online from npmjs via esm.sh; it is not included locally.

Define target_y(state) and return the desired top position of the CPU paddle. The state contains the ball position and speed, CPU paddle position, field height, ball radius and a random noise value.

Default strategy active.
